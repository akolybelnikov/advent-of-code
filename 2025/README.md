# Advent of Code 2025

Solutions for [Advent of Code 2025](https://adventofcode.com/2025) written in Elixir.

## Prerequisites

- [Elixir](https://elixir-lang.org/install.html) version 1.14+ installed

## Build

Compile the project:

```bash
mix compile
```

## Running Solutions

Run a specific day's solution:

```bash
mix run -e "DayXX.solve()"
```

Or run with Mix tasks:

```bash
mix dayXX
```

## Testing

Run all tests:

```bash
mix test
```

Run tests for a specific day:

```bash
mix test test/dayXX_test.exs
```
